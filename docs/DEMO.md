# Reproduce the development demonstration

Use only fictional records. Start `npm run worker:simulator`, then build and run `npm run preview`; open localhost:3001 in a fresh browser context. `npm run test:browser` generates screenshots of the completed software workflows.

1. Open Command Centre. The new isolated workspace has three fictional assignment records, a zone-mapped training camera and explicitly unavailable measurements. No live sensors or evaluated PPE source is claimed.
2. Submit an unfamiliar fictional report, such as “Pump P2 stopped at 10 am. Water was rising near the east sump. No injury reported.” Leave the observation date blank if unknown.
3. Extract using a genuinely configured text model, or inspect the honest unavailable state and enter reviewed facts manually. Preserve negation and unresolved date, and retain supporting source excerpts. Acceptance creates observations and a fresh immutable assessment.
4. Review the concern in Command Centre, inspect source excerpts/unknowns and open a case with owner/due date. A configured explanation model can propose source-linked paragraphs; no provider is simulated if unavailable.
5. In People and Response, record acknowledgement and a completed action. Move through verification before closure; choose real recorded evidence and a meaningful review reason in any genuine evaluation. Reopening preserves history.
6. Freeze a muster roster for the affected zone and record each human confirmation. No laboratory arrival confirms actual presence.
7. Clone the workspace in Simulator Lab. Review fictional storage/pump/flow/route assumptions; set a 24-hour horizon and e.g. 30 m³/h inflow. Run the baseline, then a backup-pump scenario. Compare curves, overflow, conservation, thresholds and routes. Change backup delay; the old result becomes outdated until a new run.
8. On Mine Map select the saved laboratory overlay and move playback. Calculated water levels/route intervals change with time without changing workspace data. A blocked-route example or advanced schedule can produce no route under this model.
9. To exercise a contrasting unsupported concern, accept a negated report or a reviewed correction. Historical assessments remain accessible in scoped exports.
10. Disconnect after visiting Evidence. Queue a report, reload, reconnect and sync. The draft remains scoped to the current session; duplicate retries create one record.
11. Inspect the exported JSON/readable response timeline and numerical evaluation evidence. The text candidate set still lacks independent labels; vision has zero reviewed source clips.

Actual PPE and reconstruction steps are **blocked**, not replaced with saved detections or invented assets. Supply licensed model weights and capture material, then process real decoded frames, review event evidence and import the independently produced reconstruction with source/scale metadata. The separately generated triangle GLB/ONNX mathematical tests verify plumbing only and are excluded from model-accuracy or reconstruction claims.

A fresh demonstration is a new browser session/context or the secondary menu's leave-session action after queued content is handled. It creates a new isolated fixture without deleting historical data. No external emergency or telecom notification is sent.
